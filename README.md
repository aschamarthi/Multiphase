Code for the paper https://doi.org/10.1016/j.jcp.2025.114157

Sainadh Chamarthi, "Wave-appropriate multidimensional upwinding approach for compressible multiphase flows" Journal of Computational Physics Volume 538, 1 October 2025, 114157. 

It simulates the Example 4.9 in the paper. The code is not "exactly" as in the paper, the THINC part is not included but it still outperforms existing schemes. Nearly SOTA (as the THINC part is not included, it can be done though)

No GPUs are harmed during this work :)
